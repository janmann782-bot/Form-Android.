FORM MOBILE - ПОРТ ДЛЯ ANDROID

Это исходники Android-приложения. APK пока НЕ собран и на реальном телефоне НЕ проверен.

КАК ПОЛУЧИТЬ APK ЧЕРЕЗ GITHUB:
1. Создай пустой репозиторий GitHub с веткой main.
2. Загрузи содержимое этой папки вместе с скрытой .github/.
3. Открой Actions -> Build Form Android APK -> Run workflow.
4. После успешного запуска открой Artifacts -> Form-Mobile-debug-APK.
5. Скачай ZIP с app-debug.apk. Распакуй и установи на Android 10+.

ЧТО ИЗМЕНЕНО:
- Адаптированный интерфейс для вертикального/горизонтального экрана.
- Выбор логотипов через стандартное приложение "Файлы".
- Сохранение PNG/WebM в Downloads/Form.
- Режим качества 1K по умолчанию (2K/4K доступны).
- Без интернета после установки: графический движок и ресурсы внутри APK.

ВАЖНО:
- Интернет нужен при сборке APK: Gradle получает готовый dist оригинального Form.
- Возможны ограничения WebGL и WebCodecs на конкретном телефоне.
- 4K видео может не кодироваться, даже если обычное PNG работает.
- Публичное распространение надо согласовать с правообладателем оригинального Form: в репозитории не обнаружена общая лицензия.
